SEPEHR CAR GALLERY 3.0

نصب:
1) قبل از هر تغییری از پوشه فعلی پروژه Backup بگیر.
2) ZIP را Extract کن.
3) فایل‌های CLS.html، car-details.html، contact.html، admin.html، style.css و script.js را در پوشه پروژه کپی کن.
4) پوشه images فعلی خودت را نگه دار؛ ۱۱ نام تصویر قبلی همچنان استفاده می‌شوند.
5) CLS.html را با Live Server اجرا کن.

امکانات:
- گالری چندتصویری در صفحه جزئیات؛ نام عکس‌های بیشتر را از پنل Admin اضافه کن.
- وضعیت موجودی: available / reserved / sold.
- پنل افزودن، ویرایش و حذف خودرو.
- فرم درخواست بازدید و نمایش درخواست‌ها در پنل.
- ثبت نظرات مشتریان.
- پیام‌های فرم تماس در پنل مدیریت.

محدودیت مهم:
این نسخه Front-end و آزمایشی است. داده‌ها فقط در localStorage همین مرورگر و همین دستگاه ذخیره می‌شوند. فرم‌ها ایمیل ارسال نمی‌کنند. پنل Admin هیچ احراز هویتی ندارد و نباید به عنوان پنل امن روی اینترنت منتشر شود. برای استفاده واقعی باید Backend، دیتابیس، ورود امن مدیر و سرویس اعلان اضافه شود. مشخصات و قیمت خودروها نمونه‌اند و باید بررسی شوند. عکس‌هایی که در پنل وارد می‌کنی باید واقعاً داخل پوشه images وجود داشته باشند.
